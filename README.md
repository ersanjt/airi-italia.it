# AIRI Italia

Public website repository for the AIRI Italia initiative.

## Overview

This repository currently contains a lightweight static website.

### Structure

- `index.html` — main public page
- `UPLOAD_README.txt` — deployment/upload notes

## Local preview

You can open `index.html` directly in a browser, or serve the repository locally:

```bash
python -m http.server 8080
```

Then visit:

```
http://localhost:8080
```

## Contribution notes

Keep changes small and reviewable. For visible changes, include screenshots in the pull request.

Do not commit credentials, private organizational documents, personal data, or server configuration containing secrets.

## Status

The repository is intentionally lightweight. Additional architecture and deployment documentation should be added as the project grows.
